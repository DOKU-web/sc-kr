자세히 보기
제공 중

자원 번역팀이 게임 업데이트를 따라가며 번역을 계속 다듬습니다. 빠진 항목은 영어 원문으로 채워 빈칸이 없도록 합니다.

자세히 보기
제공 중

런처를 켤 때마다 런처 자체와 언어팩 버전을 각각 확인해, 새 버전이 있으면 바로 알려줍니다.

자세히 보기
제공 중

런처의 커뮤니티 탭에서 파티원 모집과 중고 장터 게시판을 바로 씁니다. 런처에서 쓴 글은 SC-KR 디스코드 포럼에도 자동으로 올라갑니다.

v5.0부터자세히 보기

02 — LAUNCHER

켜면 상태부터 보여주는 런처

게임 경로를 한 번 지정하면, 런처가 언어팩 상태를 확인하고 버튼 한 번으로 최신 번역을 적용합니다.

  • 상태 카드게임 빌드, 언어팩, 파일 상태, 런처 버전을 홈 화면에서 한눈에 확인합니다.
  • 안전한 업데이트런처·언어팩 파일은 SHA-256까지 확인한 뒤 적용하고, 실패하면 이전 런처로 돌아갑니다.
  • 적용 전 미리보기 · 복구바뀔 내용을 미리 보고, 적용 직전 파일을 보관해 되돌릴 수 있습니다.
런처 다운로드
03 — SETUP

네 단계면 준비 끝

설치 프로그램이 따로 없습니다. exe 하나만 받으면 됩니다.

  1. 01

    다운로드

    SC-KR-Launcher.exe를 받아 원하는 폴더에 둡니다.

  2. 02

    폴더 지정

    스타시티즌 LIVE 폴더 경로를 확인·지정합니다.

  3. 03

    적용

    ‘자동 다운로드 및 적용’ 버튼을 누릅니다.

  4. 04

    실행

    게임을 켜면 한국어로 표시됩니다.
