01 — FEATURES

런처 하나로 처리합니다

자동 다운로드 및 적용

최신 한국어 패치를 받아 지정한 스타시티즌 LIVE 폴더에 바로 적용합니다. 버튼 한 번이면 끝입니다.

한국어 채팅

한영키로 게임 채팅창에서 직접 한글을 조합해 입력합니다. 패치를 쓰는 다른 플레이어 화면에는 정상적인 한글로 보입니다.

커뮤니티 번역

자원 번역팀이 게임 업데이트를 따라가며 번역을 계속 다듬습니다. 빠진 항목은 영어 원문으로 채워 빈칸이 없도록 합니다.

아이템 데이터 뷰어

Data.p4k에서 함선·부품 데이터베이스를 직접 추출해 표로 확인하고 검색할 수 있습니다.

자동 업데이트 확인

런처를 켤 때마다 런처 자체와 언어팩 버전을 각각 확인해, 새 버전이 있으면 바로 알려줍니다.

RSI 계정 연동

함선 즐겨찾기를 불러와 정리하고 확인할 수 있습니다.
